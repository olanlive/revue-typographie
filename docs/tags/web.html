Composite Font Studio

Compose une fonte mixte CJK + latin à la manière des fontes composites d'InDesign : taille, ligne de base et graisse réglées par classe de caractères. Export CSS ou TTF/OTF/WOFF2, sans envoi des fichiers. MIT, gratuit ; projet très jeune (octobre 2026).

Furifont 0.6

Police japonaise affichant seule les furigana au-dessus des kanji, sans balise ruby ni JavaScript, via des ligatures. Dérivée de Source Han Sans et Serif, avec une version variable et une CLI pour créer sa variante. Polices OFL 1.1, code MIT ; jeune projet (0.6.2, oct. 2026).

Fontaine 1.0.2

Outil JavaScript qui génère des polices de repli calées sur les métriques de la police web, pour éviter le saut de mise en page au chargement. La 1.0.2 (21 oct.) ajoute des replis Liberation compatibles en métriques et repère mieux les polices locales. MIT, projet unjs mûr.

Capsize

Outil web et bibliothèque CSS qui rognent l'espace vide au-dessus et sous le texte grâce aux métriques de la police : un titre s'aligne enfin pile sur la grille. La mise à jour des métriques (15 oct.) couvre les nouveautés Google Fonts d'octobre. MIT, stable depuis 2020.

Trouvé via : GitHub — seek-oss/capsize

Wavefont et Linefont — des graphiques écrits en texte

Deux polices variables de Dmitry Iv. : chaque caractère devient une barre (Wavefont : formes d'onde, histogrammes) ou un point de courbe (Linefont : séries temporelles). Idéal pour des mini-graphes dans une UI web sans canvas. Mises à jour sur Google Fonts le 9 oct. OFL 1.1.

Trouvé via : GitHub — google/fonts PR #11050 et #11051

Fontsource

Des milliers de polices libres en paquets npm à auto-héberger : un import et la police, statique ou variable, est servie par son propre site, sans CDN tiers. Catalogue en ligne pour tester. Code MIT, chaque police garde sa licence (souvent OFL).
