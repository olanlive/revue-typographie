Cal Sans 2.011

Cal.com's geometric sans, now a variable system: weight 400–700, optical sizes 8–45 pt, a GEOM axis (from A11y to Geo), real italics. 2.011 (Oct 15) adds Cal Sans Phlex, morphing letterforms without avar2. OFL 1.1; Flex is still experimental.

Found via: GitHub — calcom/sans v2.011

Kode Mono 2.003

A coding monospace with ligatures and Powerline glyphs. The 2.0 series adds two variable axes, width (75–125) and roundness (ROND 0–100), plus an ss01 set that tells D/0/O and 8/B apart. 2.003 (Oct 8) is heading to Google Fonts. OFL 1.1, mature since 2023.

Found via: GitHub — google/fonts PR #11054

Wavefont and Linefont — charts written as text

Two variable fonts by Dmitry Iv.: each character becomes a bar (Wavefont: waveforms, histograms) or a curve point (Linefont: time series). Great for tiny charts in a web UI without canvas. Updated on Google Fonts on Oct 9. OFL 1.1.

Found via: GitHub — google/fonts PRs #11050 and #11051

Libron 0.31

A reading serif derived from Readerly (itself based on Newsreader), hand-edited in FontForge for a calmer texture. Ready-made builds for Kobo, KOReader, Kindle, desktop and web. 0.31 (Oct 9) adds fractions, superscripts and Unicode spaces. OFL, in active development.

Found via: GitHub — nicoverbruggen/libron v0.31
