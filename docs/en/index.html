fontc 1.0 — Google's font compiler in Rust

Stable release (Sept 1, 2026) of Google Fonts' Rust compiler, a drop-in replacement for fontmake for Glyphs or UFO sources: variable fonts compiled much faster. TrueType only, no static instances. Apache 2.0, tested on ~3,450 targets.

fontTools 4.67

The Python Swiss Army knife for fonts (ttx, subset, varLib) at 4.67 (Oct 14, 2026): instancing of COLRv1 variable fonts, feaLib and CFF2 fixes. For slimming a web font, freezing an axis or scripting a pipeline. MIT, very mature.

Found via: GitHub — fonttools 4.67.0

Geist 1.8.1

Vercel's Geist Sans and Geist Mono, understated, for UI and code. 1.8.1 (Oct 16, 2026) aligns binary versions with the package and fixes the lowercase omega, which pointed to the Ohm sign. OFL 1.1, regular releases since 2023.

Monaspace 1.4

GitHub Next's monospace superfamily (Neon, Argon, Xenon, Radon, Krypton) with “texture healing” that balances wide and narrow letters. 1.400 adds Cyrillic, Greek, Vietnamese and IPA. Variable, web and Nerd Fonts. OFL 1.1.

Found via: GitHub — monaspace v1.400

Maple Mono 7.9

Rounded monospace for IDEs and terminals: ligatures, Nerd Font icons, a script to freeze your variants (a “Normal” option close to JetBrains Mono). 7.9 adds IPA glyphs and fixes feature freezing. OFL 1.1, ~29,000 stars.

Found via: GitHub — maple-font v7.9

October 17, 2026

Fontsource

Thousands of free fonts as npm packages to self-host: one import and the font, static or variable, is served by your own site, with no third-party CDN. Online catalog for testing. MIT code, each font keeps its own licence (often OFL).

Found via: GitHub — fontsource

Collletttivo — Italian libre foundry

Italian collective whose whole catalog is under the SIL OFL: Apfel Grotezk, Ronzino, Sprat (18 weights + variable), Halibut, Necto Mono… Expressive display faces usable commercially and in renders, with credit requested.

Atkinson Hyperlegible Next

2024 version of the Braille Institute's hyperlegible typeface: new glyphs, revised kerning, 6 weights with italics (versus 2). OFL 1.1, sources on GitHub, on Google Fonts. Ideal for UI, subtitles and docs.

Found via: GitHub — googlefonts

Inter 4.1

The reference screen sans-serif (OFL 1.1), variable with an optical size axis and many OpenType features (tabular figures, alternates). A mature project; latest version 4.1 (Nov 2024). A safe choice for interfaces and pairing.
