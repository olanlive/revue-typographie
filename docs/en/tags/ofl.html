Redaction — the legal-document serif, coming to Google Fonts

Serif by Jeremy Mickel (MCKL), between Times and Century Schoolbook, in 7 families: one clean and six increasingly "photocopied" (10 to 100). Great for textured titles or an archival look. OFL 1.1, Google Fonts onboarding under way (Oct 2026).

Iosevka 34.9

A narrow, fully configurable monospace (glyph variants, custom builds), available as Term, Slab, Aile and Etoile. 34.9 (Sept 26, 2026) adds variants for ζ, ξ, ς and dozens of diacritics. OFL 1.1, a very mature project since 2015.

IBM Plex Mono variable

Plex Mono is finally a variable font: one file, weight axis from 100 to 700, Thin to Bold instances. Handy for code and web UI without juggling files. Joins Plex Serif and Sans variable. OFL 1.1, a very mature IBM family.

Found via: GitHub — IBM/plex-mono-variable 1.0.0

The reference screen sans-serif (OFL 1.1), variable with an optical size axis and many OpenType features (tabular figures, alternates). A mature project; latest version 4.1 (Nov 2024). A safe choice for interfaces and pairing.
