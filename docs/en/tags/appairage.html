Composite Font Studio

Builds a mixed CJK + Latin font the way InDesign composite fonts work: size, baseline and weight tuned per character class. Exports CSS or TTF/OTF/WOFF2, without uploading your files. MIT, free; a very young project (October 2026).

Gen Interface JP 0.8.1

A UI typeface blending Inter and Noto Sans JP so Latin and Japanese sit together, in two families (text and display) and eight weights, with subsetted webfonts on jsDelivr. 0.8.1 fixes per-weight baselines. Fonts under OFL, a 2026 project.

Found via: GitHub — yamatoiizuka/gen-interface-jp

October 17, 2026

Fontsource

Thousands of free fonts as npm packages to self-host: one import and the font, static or variable, is served by your own site, with no third-party CDN. Online catalog for testing. MIT code, each font keeps its own licence (often OFL).

Found via: GitHub — fontsource

October 16, 2026

Inter 4.1

The reference screen sans-serif (OFL 1.1), variable with an optical size axis and many OpenType features (tabular figures, alternates). A mature project; latest version 4.1 (Nov 2024). A safe choice for interfaces and pairing.

Found via: GitHub — rsms/inter
