October 20, 2026

Google Sans Flex 5.000

Google's brand typeface, released as open source: a geometric variable sans on five axes (weight 1–1000, width 25–151, slant, ROND roundness, optical sizes 1–144). 5.000 (Oct 9) drops the GRAD axis and refines tiny sizes. OFL 1.1, merged into the google/fonts repo.

Found via: GitHub — googlefonts/googlesans-flex v5.000

October 19, 2026

Cal Sans 2.011

Cal.com's geometric sans, now a variable system: weight 400–700, optical sizes 8–45 pt, a GEOM axis (from A11y to Geo), real italics. 2.011 (Oct 15) adds Cal Sans Phlex, morphing letterforms without avar2. OFL 1.1; Flex is still experimental.

Found via: GitHub — calcom/sans v2.011

October 19, 2026

Wavefont and Linefont — charts written as text

Two variable fonts by Dmitry Iv.: each character becomes a bar (Wavefont: waveforms, histograms) or a curve point (Linefont: time series). Great for tiny charts in a web UI without canvas. Updated on Google Fonts on Oct 9. OFL 1.1.

Found via: GitHub — google/fonts PRs #11050 and #11051

October 19, 2026

Ark Pixel Font 2026.10.16

An open source pixel font in 10 and 12 px, covering Latin and Chinese/Japanese/Korean, in monospaced or proportional versions with kerning. Perfect for a game UI or a retro HUD. Released Oct 16 (16 px dropped). Fonts OFL 1.1, code MIT, active since 2021.

Found via: GitHub — TakWolf/ark-pixel-font 2026.10.16

October 18, 2026

IBM Plex Mono variable

Plex Mono is finally a variable font: one file, weight axis from 100 to 700, Thin to Bold instances. Handy for code and web UI without juggling files. Joins Plex Serif and Sans variable. OFL 1.1, a very mature IBM family.

Found via: GitHub — IBM/plex-mono-variable 1.0.0

October 17, 2026

Geist 1.8.1

Vercel's Geist Sans and Geist Mono, understated, for UI and code. 1.8.1 (Oct 16, 2026) aligns binary versions with the package and fixes the lowercase omega, which pointed to the Ohm sign. OFL 1.1, regular releases since 2023.

Found via: GitHub — vercel/geist-font v1.8.1

October 16, 2026

Inter 4.1

The reference screen sans-serif (OFL 1.1), variable with an optical size axis and many OpenType features (tabular figures, alternates). A mature project; latest version 4.1 (Nov 2024). A safe choice for interfaces and pairing.

Found via: GitHub — rsms/inter
