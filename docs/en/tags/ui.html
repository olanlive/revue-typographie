IBM Plex Mono variable

Plex Mono is finally a variable font: one file, weight axis from 100 to 700, Thin to Bold instances. Handy for code and web UI without juggling files. Joins Plex Serif and Sans variable. OFL 1.1, a very mature IBM family.

Geist 1.8.1

Vercel's Geist Sans and Geist Mono, understated, for UI and code. 1.8.1 (Oct 16, 2026) aligns binary versions with the package and fixes the lowercase omega, which pointed to the Ohm sign. OFL 1.1, regular releases since 2023.

Inter 4.1

The reference screen sans-serif (OFL 1.1), variable with an optical size axis and many OpenType features (tabular figures, alternates). A mature project; latest version 4.1 (Nov 2024). A safe choice for interfaces and pairing.
