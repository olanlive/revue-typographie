IBM Plex Mono variable

Plex Mono is finally a variable font: one file, weight axis from 100 to 700, Thin to Bold instances. Handy for code and web UI without juggling files. Joins Plex Serif and Sans variable. OFL 1.1, a very mature IBM family.

fontc 1.0 — Google's font compiler in Rust

Stable release (Sept 1, 2026) of Google Fonts' Rust compiler, a drop-in replacement for fontmake for Glyphs or UFO sources: variable fonts compiled much faster. TrueType only, no static instances. Apache 2.0, tested on ~3,450 targets.

The Python Swiss Army knife for fonts (ttx, subset, varLib) at 4.67 (Oct 14, 2026): instancing of COLRv1 variable fonts, feaLib and CFF2 fixes. For slimming a web font, freezing an axis or scripting a pipeline. MIT, very mature.
