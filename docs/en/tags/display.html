Vavin 1.1

A Garamond for screens: derived from EB Garamond, with an x-height raised by 16% (0.72 of the cap height). Nine styles in three families, including a condensed and a display one, 503 Latin languages. Readable at small sizes, still classic. OFL 1.1, version 1.1 out Oct 2026.

Punctum — a variable dot-matrix font

A 5x7 dot-matrix font with two axes: dot size (from pinhole LED to touching dots) and shape (round to square pixel). One continuous grid, real descenders, 108 ASCII characters plus arrows. Great for info boards, HUDs or retro posters. OFL 1.1, version 1.000 (Oct 2026).

Found via: GitHub — sundyme/punctum

Libre Caslon Condensed

A narrow Caslon derived from Libre Caslon Text, now on Google Fonts: a variable condensed serif (400 to 700) with italics, rare among free fonts. Ideal for elegant headlines that fit on one line, posters or covers. OFL 1.1, maintained since 2023.

Kripa

A geometric sans for Latin and Devanagari sharing one rhythm: variable from 100 to 900, 20 character variants, discretionary ligatures, tabular figures. Handy for a bilingual identity or warm headlines. OFL 1.1, brand new, added to Google Fonts in September.

Isometra

A bold slab serif built loosely on a 60-degree isometric grid, in a single weight. For an eye used to 3D, display type that looks modeled: signage, logos, titles. OFL 1.1, a recent project (2025) added to Google Fonts in September 2026.

Tiny5 and Tiny5 Duo 2.007 — pixel type goes variable

A 5-pixel-tall pixel font, now variable: weight, width, roundness and two rare axes, BLED (ink spread, CRT glow) and JITT (jitter), plus italics. Tiny5 Duo uses 2-pixel stems. Great for HUDs and retro interfaces. OFL, merged into google/fonts on Oct 9.

Firjar — a bilingual Kufic Arabic-Latin typeface

A Kufic-inspired sans built like a compass drawing (quarter circles and clean straight lines), pairing Arabic and Latin in one variable family: weight 100–800, width 75–125. For headlines, branding and bilingual UI. By Mestara Type, OFL, added to google/fonts on Oct 15.

Cal.com's geometric sans, now a variable system: weight 400–700, optical sizes 8–45 pt, a GEOM axis (from A11y to Geo), real italics. 2.011 (Oct 15) adds Cal Sans Phlex, morphing letterforms without avar2. OFL 1.1; Flex is still experimental.
