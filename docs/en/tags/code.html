Lilex 2.630

A coding font derived from IBM Plex Mono, with ligatures and a variable version. 2.630 (Oct 5) adds ASCII control pictures, an overline, rounded commas and quotes (ss05), and fixes ligature and diacritic alignment. OFL 1.1, active since 2019.

Sarasa Gothic 1.0.42

A composite font combining Inter, Iosevka and Source Han Sans: Latin plus Chinese, Japanese and Korean that line up, including monospaced variants for terminals and code. Version 1.0.42 (Sep 26), as TTF, TTC or SuperTTC. OFL 1.1, mature and widely used.

Kode Mono 2.003

A coding monospace with ligatures and Powerline glyphs. The 2.0 series adds two variable axes, width (75–125) and roundness (ROND 0–100), plus an ss01 set that tells D/0/O and 8/B apart. 2.003 (Oct 8) is heading to Google Fonts. OFL 1.1, mature since 2023.

Found via: GitHub — google/fonts PR #11054

Iosevka 34.9

A narrow, fully configurable monospace (glyph variants, custom builds), available as Term, Slab, Aile and Etoile. 34.9 (Sept 26, 2026) adds variants for ζ, ξ, ς and dozens of diacritics. OFL 1.1, a very mature project since 2015.

IBM Plex Mono variable

Plex Mono is finally a variable font: one file, weight axis from 100 to 700, Thin to Bold instances. Handy for code and web UI without juggling files. Joins Plex Serif and Sans variable. OFL 1.1, a very mature IBM family.

Found via: GitHub — IBM/plex-mono-variable 1.0.0
