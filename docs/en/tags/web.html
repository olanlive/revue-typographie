Furifont 0.6

A Japanese font that shows furigana above kanji by itself, with no ruby markup or JavaScript, using ligatures. Derived from Source Han Sans and Serif, with a variable version and a CLI to build your own variant. Fonts OFL 1.1, code MIT; a young project (0.6.2, Oct 2026).

Found via: GitHub — antfu/furifont

Fontaine 1.0.2

A JavaScript tool that generates fallback fonts matched to your web font's metrics, so the layout doesn't jump while it loads. 1.0.2 (Oct 21) adds metric-compatible Liberation fallbacks and better matching of local fonts. MIT, a mature unjs project.

Found via: GitHub — unjs/fontaine 1.0.2

October 22, 2026

Capsize

A web tool and CSS library that trim the empty space above and below text using the font's metrics, so headings finally sit exactly on the grid. The Oct 15 metrics update covers the October Google Fonts additions. MIT, stable since 2020.

Found via: GitHub — seek-oss/capsize

October 19, 2026

Wavefont and Linefont — charts written as text

Two variable fonts by Dmitry Iv.: each character becomes a bar (Wavefont: waveforms, histograms) or a curve point (Linefont: time series). Great for tiny charts in a web UI without canvas. Updated on Google Fonts on Oct 9. OFL 1.1.

Found via: GitHub — google/fonts PRs #11050 and #11051

October 17, 2026

Fontsource

Thousands of free fonts as npm packages to self-host: one import and the font, static or variable, is served by your own site, with no third-party CDN. Online catalog for testing. MIT code, each font keeps its own licence (often OFL).

Found via: GitHub — fontsource
